Evaluation rules

Rules are deterministic checks (match, regex, JSON path, tool policy) used when a scenario’s judge mode includes rule or hybrid. Attach rule sets in Scenario Studio → step 3 Evaluate. LLM rubrics (model-graded scoring) are configured alongside the judge on that step—this page is for rule maintenance only (static mock; not persisted).

Rules vs dataset fields: rules run against captured agent output and tool trace; they do not read item_type to branch in this preview (mock). Exact / JSON path checks often align with structured outputs or fields derived from the gold (expected_answer). Regex checks often mirror must-not text in failure_signals.forbidden_phrases. Tool-call policy pairs with failure_signals.forbidden_tools and tool traces. See Test Data · How items are scored for how labels relate to authoring.
