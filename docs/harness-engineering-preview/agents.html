Agents

Agent registration and management live in the frontend app; this folder does not duplicate a static list. Below: routes and how to open them locally.

Open /agents UI Map

Frontend routes

TanStack Router · requires auth (_authenticated layout).

  • List: /agents — frontend/src/routes/_authenticated/agents/index.tsx
  • Detail: /agents/:agentId — frontend/src/routes/_authenticated/agents/$agentId.tsx
  • Implementation: frontend/src/features/agents/

Local dev: from repo root, cd frontend and npm run dev; default port follows frontend/vite.config.ts (often 3000 if PORT is unset). Change the button URL if your port differs.

Relationship to Reliability Lab previews

Harness static pages (Scenario Studio, Run Center, Reliability Home, etc.) still use demo mocks for “bind agent” and “target agent”. Real data is owned by the frontend Agents module. The sidebar keeps an Agents link so you can jump from the prototype to this page, then into the web app.
