Run Center

Create runs, batch execution, replay snapshots, and step timelines. A Run here is an evaluation execution. A Scan task is a separate mock for scheduled or on-demand scan jobs (not wired to a real API). How this maps to persisted backend Task rows is summarized on the UI Map glossary.

What works here: Browse and filter mock runs. New Run / Run selected show toasts only. Arriving from Test Data (?dataset=…) or Scenario Studio (?scenario=…) shows a banner; step 4 “Open Run Center” may store a small draft in sessionStorage for the banner below. Walkthrough → 说明：运行列表为静态示例；与真实任务系统的对应关系见 UI Map 词汇表。 结果语义：按数据集逐条比较（question 输入 vs expected_answer / failure_signals + 规则/LLM判分）后，再汇总到 run 级通过率与分数。
