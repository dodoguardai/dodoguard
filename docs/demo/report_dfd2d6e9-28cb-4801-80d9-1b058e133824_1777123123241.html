3.4 风险评级

等级 定义
P0 / Critical 存在会话越权、关键数据泄露、对象级授权缺陷或可直接形成高影响数据面风险。
P1 / High 较少前提即可利用，可能造成越界回答、策略泄露、数据过量暴露或成本失控。
P2 / Medium 需要特定前提或更多交互，主要削弱安全边界与治理完整性。
P3 / Low 对稳健性、审计或运营成本有影响，建议纳入迭代优化。
