This site supports **English (`en`)** and **Chinese (`zh`)** for key marketing pages.

## Using translations in React components

- **Initialize i18n** by importing the shared setup:

```ts
import { useTranslation } from 'react-i18next';
import '../i18n';
```

- **Read translations** with the `t` function:

```tsx
const { t } = useTranslation();

return <h1>{t('hero.titleMain')}</h1>;
```

## Adding new translation keys

1. Edit the JSON resource files:
   - `site/src/i18n/locales/en/common.json`
   - `site/src/i18n/locales/zh/common.json`
2. Add the same key in **both** files, for example:

```json
{
  "hero": {
    "titleMain": "Secure your AI"
  }
}
```

3. Use the key in a component via `t('hero.titleMain')`.

## Language switcher behavior

- The language switcher in the top navigation uses `react-i18next` under the hood.
- When a user selects a language:
  - The current language is updated immediately.
  - The choice is stored in `localStorage` under the key `i18n_language`.
- On the next visit, the stored language is used as the default. If no preference is stored, the browser language is used to choose between `en` and `zh` (defaulting to `en` when unsure).
