# replicate-lifeboat (Replicate Lifeboat)

You can run this example with:

```bash
npx dodoguard@latest init --example replicate-lifeboat
```

To get started, set your OpenAI and Replicate API tokens in dodoguardconfig.yaml.

Then, add your test cases.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
