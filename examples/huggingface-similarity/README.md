# huggingface-similarity (Huggingface Similarity)

You can run this example with:

```bash
npx dodoguard@latest init --example huggingface-similarity
```

To get started, set your HF_API_TOKEN environment variable.

Next, change a few of the prompts in prompts.txt and edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
