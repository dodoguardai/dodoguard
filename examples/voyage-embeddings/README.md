# voyage-embeddings (Voyage Embeddings)

You can run this example with:

```bash
npx dodoguard@latest init --example voyage-embeddings
```

To get started, set your ANTHROPIC_API_KEY and VOYAGE_API_KEY environment variables.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
