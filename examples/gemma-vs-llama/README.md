# gemma-vs-llama (Gemma Vs Llama)

You can run this example with:

```bash
npx dodoguard@latest init --example gemma-vs-llama
```

To get started, set your REPLICATE_API_KEY environment variable.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
