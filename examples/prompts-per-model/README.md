# prompts-per-model (Prompts Per Model)

You can run this example with:

```bash
npx dodoguard@latest init --example prompts-per-model
```

This example shows how to set up a custom set of prompts for specific models.

To get started, set your OPENAI_API_KEY environment variable.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
