# moderation (Moderation)

You can run this example with:

```bash
npx dodoguard@latest init --example moderation
```

To get started, set your OPENAI_API_KEY and REPLICATE_API_KEY environment variables.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
