# langchain-python (Langchain Python)

You can run this example with:

```bash
npx dodoguard@latest init --example langchain-python
```

This example shows how to run a Python (LangChain) chain implementation with DodoGuard. It compares GPT-4 versus LangChain's LLM Math module.

To run it, first create a virtual env and install the requirements:

Then activate the virtual env.

```sh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Then run the eval:

```
npx dodoguard eval
```
