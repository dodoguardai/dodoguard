# javascript-assert-external (Javascript Assert External)

You can run this example with:

```bash
npx dodoguard@latest init --example javascript-assert-external
```

To get started, set your OPENAI_API_KEY environment variable.

Next, edit assert.js and dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
