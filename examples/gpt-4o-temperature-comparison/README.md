# gpt-4o-temperature-comparison (Gpt 4o Temperature Comparison)

You can run this example with:

```bash
npx dodoguard@latest init --example gpt-4o-temperature-comparison
```

To get started, set the OPENAI_API_KEY environment variable.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
