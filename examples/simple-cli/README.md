# simple-cli (Simple Cli)

You can run this example with:

```bash
npx dodoguard@latest init --example simple-cli
```

This example is pre-configured in `dodoguardconfig.yaml`. That means you can just run:

```
dodoguard eval
```

To override prompts, providers, output, etc. you can run:

```
dodoguard eval --prompts prompts.txt --providers openai:chat --output output.json
```
