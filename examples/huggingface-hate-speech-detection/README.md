# huggingface-hate-speech-detection (Huggingface Hate Speech Detection)

You can run this example with:

```bash
npx dodoguard@latest init --example huggingface-hate-speech-detection
```

To get started, set your HF_API_TOKEN environment variable.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
