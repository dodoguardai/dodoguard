# openai-chat-history (Openai Chat History)

You can run this example with:

```bash
npx dodoguard@latest init --example openai-chat-history
```

To get started, set your OPENAI_API_KEY environment variable.

Next, have a look at prompt.json and edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
