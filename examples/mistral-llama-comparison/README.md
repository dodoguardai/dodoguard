# mistral-llama-comparison (Mistral Llama Comparison)

You can run this example with:

```bash
npx dodoguard@latest init --example mistral-llama-comparison
```

To get started, set your OPENROUTER_API_KEY environment variable.

Next, change a few of the text files in prompts/ and edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
