# huggingface-inference-endpoint (Huggingface Inference Endpoint)

You can run this example with:

```bash
npx dodoguard@latest init --example huggingface-inference-endpoint
```

To get started, set your HF_API_TOKEN environment variable. See also https://dodoguard.dev/docs/providers/huggingface/ for setup details.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
