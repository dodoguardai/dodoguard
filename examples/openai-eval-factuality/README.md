# openai-eval-factuality (Openai Eval Factuality)

You can run this example with:

```bash
npx dodoguard@latest init --example openai-eval-factuality
```

This example uses the factuality and closed QA evaluation method from OpenAI.

It is pre-configured in `dodoguardconfig.yaml`. That means you can just run:

```
dodoguard eval
```
