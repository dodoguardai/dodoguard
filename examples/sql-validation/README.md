# sql-validation (Sql Validation)

You can run this example with:

```bash
npx dodoguard@latest init --example sql-validation
```

To get started, set your OPENAI_API_KEY environment variable and `npm i node-sql-parser` to install the peer dependency.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
