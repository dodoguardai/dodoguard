# custom-grading-prompt (Custom Grading Prompt)

You can run this example with:

```bash
npx dodoguard@latest init --example custom-grading-prompt
```

To get started, set your OPENAI_API_KEY environment variable.

Next, have a look at the custom prompt in dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
