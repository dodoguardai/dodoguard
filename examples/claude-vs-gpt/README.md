# claude-vs-gpt (Claude Vs Gpt)

You can run this example with:

```bash
npx dodoguard@latest init --example claude-vs-gpt
```

To get started, set your OPENAI_API_KEY and ANTHROPIC_API_KEY environment variables.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
