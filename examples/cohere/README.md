# cohere (Cohere)

You can run this example with:

```bash
npx dodoguard@latest init --example cohere
```

To get started, set your COHERE_API_KEY environment variable.

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Or

```
dodoguard eval -c complex_config.yaml
```

Afterwards, you can view the results by running `dodoguard view`
