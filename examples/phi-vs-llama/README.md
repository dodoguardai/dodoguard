# phi-vs-llama (Phi Vs Llama)

You can run this example with:

```bash
npx dodoguard@latest init --example phi-vs-llama
```

To get started:

```sh
ollama pull llama3
ollama pull phi3
```

Next, edit dodoguardconfig.yaml.

Then run:

```
dodoguard eval
```

Afterwards, you can view the results by running `dodoguard view`
